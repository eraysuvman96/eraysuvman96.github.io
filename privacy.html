Privacy Policy — shorts-uploader

Last updated: November 19, 2026

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy.

shorts-uploader is a personal tool used only by the owner of the "Unsolved Shorts" YouTube channel to upload their own videos to their own channel through the YouTube Data API.

Data we access

The tool requests a single Google permission (youtube.upload) for the channel owner's account, used only to upload videos and set their title, description and tags.

Data we store or share

We do not collect, store, sell or share any personal data from any user. The only credential is the owner's own OAuth token, kept in encrypted repository secrets and used solely for uploads.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Data retention and deletion

The tool does not store any YouTube API data. The only stored item is the owner's OAuth refresh token, kept as an encrypted GitHub Actions secret. It is deleted immediately if access is revoked or the tool is retired, and in any case no API data is retained for more than 30 days. To request deletion or ask a question, contact the owner via the email address listed on the OAuth consent screen.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
